# Helm chart 0.15.0

Images: rustdesk-server 1.1.16-9, rustdesk-api 3.9.0, web client 2.1.0. Native clients: 1.5.1-1.

## Changes

- rustdesk-server 1.1.16-9: our rendezvous protocol fields move to 1001 and up (same-user access,
  device owner key, key change refused), so that upstream's new fields do not take them.
- Web client 2.1.0: built from cRustDesk 1.5.1-1 (upstream RustDesk 1.5.1 UI). Text paste uses the
  new field numbers and needs 1.5.1-1 devices. Settings do not show keyboard shortcuts, which the
  web client does not support.
- rustdesk-api: no change.

## Upgrade steps

- Upgrade the chart and the native clients (1.5.1-1) together. Devices older than 1.5.1-1 on this
  chart do not get same-user access and do not show why the server refuses a changed key; text
  paste needs 1.5.1-1 on both sides.
